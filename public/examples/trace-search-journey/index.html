선크림 검색 앞뒤로 무엇을 찾는가 — 세션 인접 검색 여정 (한국)

질문: «선크림 검색 앞뒤로 뭘 찾는지 보여줘»
시장: 한국(gl=kr) · 조회일 2026-09-30 · 데이터 시점 time_point = curr (조회 시점의 최신 월 단위 스냅샷 — 실시간이 아니다) [실제 데이터]
도구: trace-search-journey v0.2.1 (lm-skills 1.6.0) · 운영 서버

읽기 전에 — 이 리포트는 같은 검색 세션 안에서 바로 앞뒤로 붙어 나온 검색어의 집계다. 한 사람의 구매 여정, 전환율, 이탈률, 며칠 뒤의 행동, 성·연령별 차이는 이 데이터에 없다. «A 다음에 B»는 반환된 경로에서 A 바로 뒤에 B가 붙은 경로 수이며, 사람이 A를 거쳐 B로 이동해 샀다는 뜻이 아니다. 검색은 관심 신호이지 구매가 아니다.

1. 한눈에 보기

  • 선크림 바로 다음 검색은 세 갈래로 나뉜다 — «선크림 바르지마라» 5경로 · «선크림 추천» 5경로 · «선크림 종류» 5경로 (시드 뒤 인접 16건 중, 반환 20경로 기준) [실제 데이터 · 로컬 집계]. 고르는 검색(추천·종류)과 쓰는 법 검색(바르지마라→바르는법→지우는법)이 비슷한 비중으로 붙었다.
  • 선스틱 바로 다음 검색은 «선스틱 선크림 차이» 13 · «선스틱 다이소» 10 · «선스틱 나무위키» 9경로 (시드 뒤 인접 33건 중, 반환 40경로 기준) [실제 데이터 · 로컬 집계]. 선스틱과 선크림의 차이를 확인하는 검색과 다이소 채널 검색이 앞에 섰다.
  • 선스틱 뒤 두 걸음: «선스틱 선크림 차이» → «선크림 추천» 13경로 · «선스틱 다이소» → «다이소 선크림» 10경로 · «선스틱 나무위키» → «선크림 추천» 9경로 [실제 데이터 · 로컬 집계]. 차이·백과 검색 다음 걸음이 모두 «선크림 추천»으로 모인다.
  • 앞 검색은 표본이 작다 — 선크림 앞 인접 4건, 선스틱 앞 인접 7건. 선스틱 바로 앞에서 가장 많은 검색어는 «올리브영 선쿠션 추천»(5건)이다 (선쿠션·선팩트 추천에서 선스틱으로 붙는 경로) [실제 데이터 · 로컬 집계].
  • 판정 보류: 두 시드 모두 반환 경로 수가 요청 limit에 닿았다(절단). 위 비중은 반환분 기준이며 «선크림 검색 앞뒤 전체»로 일반화하지 않는다. 두 시드의 limit이 달라(20·40) 서로 비중·순위를 나란히 비교하지 않는다 [가정].

4. 숫자를 읽을 때의 주의

  • 선크림: 반환 20경로 중 4경로가 같은 앞 세 걸음(«선크림 → 선크림종류 → 유기자차선크림», 정규화 표기)을 공유한다(뒤쪽만 갈라지거나 거기서 끝난다) [실제 데이터]. 반환 경로는 공통 줄기에서 끝만 갈라지는 형태가 많아, 인접 경로 수는 «세션 빈도»라기보다 «그 줄기 아래 갈래 수»에 가깝게 커질 수 있다 [추정].
  • 선스틱: 반환 40경로 중 13경로가 같은 앞 세 걸음(«선스틱 → 선스틱선크림차이 → 선크림추천», 정규화 표기)을 공유한다(뒤쪽만 갈라지거나 거기서 끝난다) [실제 데이터]. 반환 경로는 공통 줄기에서 끝만 갈라지는 형태가 많아, 인접 경로 수는 «세션 빈도»라기보다 «그 줄기 아래 갈래 수»에 가깝게 커질 수 있다 [추정].
  • «선크림» 요청의 응답은 시드를 «썬크림» 20경로 표기로 돌려줬다 [실제 데이터]. 단계 사전의 변형치환(썬→선)으로 같은 검색어로 묶어 셌다 — 이 치환이 없으면 시드가 경로에서 한 번도 잡히지 않는다 [가정: 변형치환 규칙].
  • 경로의 끝은 이탈이 아니라 세션·데이터의 끝일 수 있어 이탈률을 계산하지 않았다.

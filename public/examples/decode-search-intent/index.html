선크림 — 사람들은 왜 검색하나 (검색 의도 분해 · gl=kr)

발화 «선크림 검색 의도 분석해줘» · 스킬 decode-search-intent v1.2.1 · 출발 검색어 3개(선크림 · 선스틱 · 무기자차 선크림) 데이터 기준월 2026-08 · 조회일 2026-09-30 · 검색량은 기준월로 끝나는 12개월 합(단위 건) [실제 데이터] 이번 분석 소진 1,739 크레딧(호출 5건 cost_detail.total_cost 합) [실제 데이터]

먼저 읽을 것 — 이 분포는 «확정»이 아니다

  • 연관 검색어 확장 3건이 모두 요청 한도(100개)에 걸려 잘렸다(3/3). 그래서 아래 숫자는 «선크림 시장의 의도 구성»이 아니라 검색량 상위 표본의 구성이다. 잘려 나간 꼬리에는 대개 니즈·목표 검색어가 몰리므로 L1·L2 비중은 최소치로 읽는다. → 판정: 분포 확정 보류 [데이터 공백]
  • 표기가 갈린 검색어(썬크림/선크림 등)는 한 묶음으로 세되, 같은 검색인지 다른 검색인지 응답으로는 알 수 없어 **하한(묶음 최댓값) ~ 상한(묶음 합)**을 함께 적는다: 전체 10,957,003 ~ 12,924,647건, 묶음 298개 [추정]. 비중·순위·결론은 하한 기준이다.
  • 층·단계 분류는 이 분석용으로 새로 쓴 규칙 사전(intent_dict.json)의 결과다. 정확도 수치는 붙이지 않는다 [가정].

핵심 결과

  1. 검색의 62.1%(하한 기준)가 브랜드를 붙인 검색이다 — 브랜드 묶음 185개 · 논브랜드 113개. 선크림 검색은 «무엇을 살까»보다 «이미 아는 제품 찾기»가 크다 [추정].
  2. 논브랜드 검색의 87.6%가 해결책 층(제형·차단 방식: 톤업·무기자차·선스틱 등) 이다. 니즈·목표 표현은 주 층이 아니라 해결책 검색어 안에 섞여 나온다 [추정].
  3. 상황·사용자(L2) 표현이 니즈(L1)보다 크다 — 출발 검색어 표현을 뺀 논브랜드 묶음 기준 L2 22개 · 613,145건, L1 12개 · 67,474건. L2 상위는 워터프루프 선크림, 파데프리 선크림, 남자 썬크림, 아기 선크림 [추정 · 절단으로 하한].
  4. 단계 수식어가 붙은 논브랜드 검색(1,454,996건) 안에서는 구매 44.6% · 비교 43.7% · 탐색 11.6% 이다. 논브랜드 구매 검색량의 100.0%가 채널명(다이소·올리브영·PX 등)이 붙은 검색이다 — 채널을 구매 단계로 본 것은 [가정].
  5. API 의도 라벨과의 대조는 11묶음뿐이라 결론에 쓰지 않는다(기준 20 미만). 다만 규칙이 «비교»로 본 추천 검색어 5개는 모두 API에서 비교(c) 플래그가 꺼져 있었다 — 사전 점검 대상 [실제 데이터 · 표본 작음].

1. 의도 층 분포 — 전체 vs 논브랜드

층은 L1 니즈(불편) → L2 목표(원하는 결과·상황·사용자) → L3 해결책(제품 유형) → L4 제품(라인명) → L5 브랜드. 검색어 하나가 여러 층 표현을 담으면 하류 층이 주 층이 된다(해결책을 말했으면 이미 니즈 단계를 지났다는 가정) [가정].

«출발 검색어 표현 제외»는 시드에 들어 있는 사전 표현(예: 시드 탈모샴푸의 탈모)만으로 걸린 층을 뺀 값이다. 니즈 근거로는 이 열을 쓴다 — 시드 토큰은 모든 반환에 들어가 포함률을 자명하게 만든다.

  • 콘텐츠: 해결책 검색어에 붙은 상황·사용자(남성·아기/유아·워터프루프·메이크업 궁합)를 축으로 묶는다. 니즈(백탁·끈적임·눈시림)는 무기자차 비교 콘텐츠 안의 하위 주제로 둔다 [추정].
  • 광고: 수식어 없는 헤드 검색어도 API에서 구매(t) 플래그가 다수 켜져 있다 — 헤드 검색어를 «정보 탐색 전용»으로 분류해 제외하지 않는다 [추정].
  • 브랜드 방어: 검색 과반이 브랜드 검색이므로 자사·경쟁 브랜드 검색어는 이 표의 L5 목록으로 따로 관리한다.
  • 다음 분석: 니즈 표현 시드로 확장 1회 + 2단 표본 확대(추천 검색어 라벨 점검) 후 분포를 다시 판정한다.

결정·가정 기록

  • 사용자 확인 단계는 SKILL.md 기본값으로 정했다 — request.md 참조(시장·경계·출발 검색어·예산 계산).
  • 사전 v2: 자작나무 수분 선크림(라운드랩 라인명)의 수분이 L1 니즈로 잡혀 L1 포함률이 부풀어 제외 패턴을 넣고 STEP 6을 다시 돌렸다(크레딧 불필요). 이전 사전은 intent_dict.v1.json.
  • 2단 조회 대상(gated.json)은 사전 v1로 뽑았다. v2로 다시 뽑으면 2개가 바뀐다(gated.v2_check.json) — 재조회하지 않았다.
  • 채널명(올리브영·다이소·쿠팡·PX·군마트·알리·편의점)은 브랜드가 아니라 구매 단계 신호로 봤다 [가정]. 라인명(자작나무·어성초 등)은 L4 제품으로 두어 논브랜드에 포함된다 [가정].
